- **How to run the Fidelity scan cheaply (2026-10-10, Journal `QTR-REVIEW-1-FIDELITY-SCAN`).** One page per ticker holds every tab: `https://digital.fidelity.com/prgw/digital/research/quote/dashboard/view-all?symbol=TICKER` (Claude in Chrome). Don't `get_page_text` it (about 19K characters, mostly news, profile and filings); run a read-only page script that splits `main.innerText` into lines and returns only: the Price performance block, the line after "Upcoming events", the Beat/Missed lines, P/E (TTM) and P/E (5-year avg) vs industry, EPS growth, the Analyst ratings label and score, and the firm / opinion rows between "Opinion date" and "Explore all research firms". Script output is capped near 1,000 characters and is blocked if it contains `=`, `&` or `?`, so strip those. Wait for "Key statistics for" before reading (sections load late). Fidelity shows no multi-period price block for ASML, TSM or PLD. The script is kept in `docs/ops/fidelity_scan.js`. **After every scan, save its text and run `python -m landry fidscan add --file FILE --as-of YYYY-MM-DD`** (the date the data is as of): it stores the scan in `landry_fidelity_scans.json` with that day's Landry composite and Market Data price, and prints Fidelity's Equity Summary Score against the Landry composite (rank gap, disagreement flags, and the price change since each earlier scan). `landry fidscan report` reprints it. The Equity Summary Score is context and a disagreement flag only, never a Scoring input (Alan, 10/10/26, Journal `FIDELITY-VS-LANDRY-SCORE`): on the first snapshot it tracked 3-month price (+0.66) far more than the Landry composite (+0.28).

- **Relative Strength trend: persistence review and tie-breaker (Alan, 2026-10-10, "go with a, b and d"; Open Items #47, Journal `RS-TREND-POLICY`).** `python -m landry rs-trend [TICKERS]` reads the blended 6/12-month gap vs SPY every 13 weeks back and reports the 3/6/12-month gaps, the streak and the state for the held scored stocks plus any candidates named. PERSISTENT = same sign three or more quarterly readings in a row AND further that way than the last reading. (a) A HELD name that is persistent down with a Relative Strength score of 2 or lower is on the Rule 5 review: no additions (DCA included) and a written re-underwrite in the Journal within 10 trading days, repeated every 90 days while it lasts; a review trigger, never a sale on price alone. (b) Among tranche candidates that already pass every gate, persistent up is the tie-breaker; a persistent-down candidate needs the Rule 5 review before a Buy / Strong Buy is relied on. (d) Every `landry draft` now writes the 3-month gap, the streak and the quarter-on-quarter move into the Relative Strength rationale, and `landry weekly` prints an "RS trend" line. The 3% composite weight is unchanged (the evidence, `landry rs-test`, does not support raising it yet). The rulebook text for (a) is drafted in the Journal entry and waits for the v1.06 revision; until then this note and the Journal are the policy.
