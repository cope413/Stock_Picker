Spec

Weights

From an empty cache to today's trade list. Tab names below are clickable.

  1. Run the first build

    On the Pipeline tab, click Run full build. The first run downloads the full universe via yfinance and sweeps every strategy config across every asset (~20,000 backtests over ~120 assets) — expect it to run for a while. Then: survival funnel → deflated Sharpe → one holdout pass → correlation clustering → equal-risk-contribution weights → today's signals. The log streams live; one job runs at a time.

    The form next to the button holds the portfolio knobs:

    KnobDefaultWhat it controls
    Correlation threshold0.70 How aggressively near-duplicate strategies are merged into one idea
    Target vol0.10 Annualized portfolio volatility the weights are scaled to
    Max weight / strategy0.25 Cap on any single strategy's share of gross
    Max gross leverage1.0× Gross-leverage ceiling
    Min DSR0.95 Deflated-Sharpe floor for a strategy to be eligible

    The scan universe is the built-in list (index/sector/macro ETFs, crypto, the S&P 100) plus any tickers you add in the Universe box on the same tab.

    If nothing clears the DSR floor and a positive holdout Sharpe, no portfolio is built — that is the system working, not failing. An empty book beats a book of noise.

  2. Read the results

    • Verdict strip (top of every tab) — independent edges, achieved vol, gross, and data freshness with a staleness lamp. The only numbers that matter at a glance.
    • Signals — net exposure per asset (the trade list) plus per-strategy position × weight detail.
    • Holdout — each survivor scored once on data the sweep never saw. This is the number to believe; everything in-sample is descriptive only.
    • Clusters — which strategies were merged as one idea, and which representative survived.
    • Portfolio — the saved spec: weights, vol scaling, caps.

  3. Daily routine

    Once a spec exists you don't rebuild every day. On the Signals tab:

    • Update with fresh data — pulls the latest bars, then recomputes today's positions from the saved spec. The one-click daily run.
    • Update signals — same, but from cached data (no download).
    • The staleness lamp in the verdict strip warns when the cache is too old to trust.

    Rebuild (step 1) only to change the knobs or re-qualify the strategy set; Refresh data only on the Pipeline tab just updates the cache.

  4. CLI equivalents

    The web UI and the CLI write the same artifact files (layer5_holdout.csv, layer6_clusters.csv, layer6_portfolio.json, layer6_signals.json) and stay interchangeable:

    python layer6_portfolio.py                      # = Run full build
python layer6_portfolio.py --signals            # = Update signals
python layer6_portfolio.py --signals --refresh  # = Update with fresh data
python layer6_portfolio.py --corr 0.6 --vol 0.08 --max-weight 0.2 \
                           --max-gross 1.5 --min-dsr 0.9   # custom knobs

Before trusting any output

The large-cap list (AAPL, MSFT, NVDA, …) is 2025's known winners backtested from 2010 — long-biased results on that group are inflated by survivorship bias. Costs are simplified: per-side bps on turnover, no slippage model, shorting treated as free. See the Layer 5 cost-sensitivity report for which results are fragile to that assumption.
